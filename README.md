# Certified Specialist in Data Science and Analytics

This repository contains all coursework, lab assignments, practical exercises, and capstone projects completed as part of the **Certified Specialist in Data Science and Analytics** program offered by the **ICT Academy of Kerala (ICTAK)**.

---

## 📌 Overview

The program covers end-to-end data science workflows, focusing on statistical analysis, data processing, machine learning modeling, and analytical reporting. This repository serves as a centralized log of code, datasets, and analytical findings developed throughout the course.

---

## 🛠️ Tech Stack & Tools

* **Programming Language:** Python
* **Data Handling & Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn
* **Environment:** Jupyter Notebooks, VS Code
* **Version Control:** Git, GitHub
